## 1. What changed (owner decision: custom PHP runtime)

**PHP 8.3.35**
- Built by the repository from the official release source (sha256 `ff4630fb…619a`).
- The signature is checked against the pinned PHP 8.3 release-manager fingerprints; the `VALIDSIG` came from Jakub Zelenka.
- Built with the official docker-library configure flags, **unmodified: no source patch**. The only deviation is omitting `--with-pear` (dev tooling whose install fetches an unverified phar).

**curl 8.22.0**
- Source sha256 `f7ef3ae8…f4f7`; `VALIDSIG` from Daniel Stenberg's key `27ED…12C2`.
- libcurl only: OpenSSL (Debian's `libssl3t64`), nghttp2, zlib, libidn2, libpsl, and the Debian CA bundle.
- Protocols **HTTP/HTTPS only**; WebSockets, FTP, LDAP, SMB, telnet and the rest are disabled; no CLI.

**libxml2 2.15.4**
- Source sha256 `98087fd1…8821`, matching GNOME's published checksum (GNOME publishes no signature).
- Default configuration without Python bindings.

**Build**
- Everything is built in digest-pinned stages. The official `php:8.3.35-fpm-trixie` image is now build-only (toolchain and `docker-php-*` scripts).
- Debian's libcurl/libxml2 are purged, and their `-dev` packages are never installed. configure resolved `libcurl >= 7.29.0` and `libxml-2.0 >= 2.9.0` from `/usr/local/lib/pkgconfig`.
- The compile against the new libxml2 ABI succeeded with **no source change** and no libxml2 deprecation warnings (5 compiler warnings in total).

**Runtime (`debian:13.7-slim`, the official image's own base)**
- Contains only the shared libraries PHP, nginx and TLS need; no Debian libcurl or libxml2.
- The patched `libcurl.so.4` and `libxml2.so.16` live in `/usr/local/lib`, registered through `/etc/ld.so.conf.d/00-lycenza-native.conf` and `ldconfig`.
- `STOPSIGNAL SIGQUIT`, `PHP_INI_DIR` and the FPM configuration reproduce the official image.
- No headers, source, phpize, php-config, PEAR or compiler.
- 111 Debian packages (was 122).

**SBOM**
- Syft identifies `php-cli`/`php-fpm` 8.3.35 and each extension by itself.
- libcurl and libxml2 carry standard ELF `.note.package` metadata (FDO packaging metadata), so Syft lists `curl 8.22.0` and `libxml2 2.15.4`. No SBOM is hand-edited.
- Detection was proven: notes claiming curl 8.14.1 and libxml2 2.9.14 made Grype report curl 8 CRITICAL + 17 HIGH and libxml2 findings; the real 8.22.0/2.15.4 notes produce none.
- Limit: for these libraries Grype relies on NVD CPE data. Distro-only advisories do not apply to them, so upstream advisory checks are part of the update runbook.

**Provenance.** The resolved dependencies now include the three source archives (URL + sha256) alongside every base-image digest (`LYCENZA_*_URL`/`_SHA256`, parsed by the release tooling).

## 2. Evidence

**Extension parity.** `php -m` is identical to the official-binary image: 40 modules, committed as `infrastructure/docker/production/php-modules.expected`.

**Dynamic linkage** (`ldd`, inside the image). `php` and `php-fpm` resolve `libcurl.so.4 => /usr/local/lib/libcurl.so.4` and `libxml2.so.16 => /usr/local/lib/libxml2.so.16`. No binary or extension has an unresolved library. The only libcurl/libxml2 files anywhere in the filesystem are those two.

**Native smoke inside the production image**
(`runtime-checks/php-native-smoke.php`, 3 rounds plus a fresh process, all passing):
- the webhook HTTP client stack (Laravel HTTP client → Guzzle → libcurl) over real TLS with a throwaway CA and `CURLOPT_RESOLVE` pinning;
- refusal of an untrusted CA and of a hostname mismatch;
- redirects returned, not followed; the total timeout enforced; a refused connection handled;
- an AWS SDK round trip against a real MinIO (HTTP plus S3 XML responses, including an XML error);
- DOM/XPath, SimpleXML, XMLReader, XMLWriter;
- XXE not expanded; structured libxml errors;
- mail CSS inlining (css-to-inline-styles).

No segfault, abort, symbol or loader error.

**verify-images.sh: 82/82.** The 14 new checks fail against the previous official-binary image, as intended.

**Guards.** `CustomPhpRuntimeGuardTest` has 6 tests. Four mutations were all caught: runtime back on the official image, Debian libxml2-dev reintroduced, Debian libcurl in the runtime, and runbook checksum drift.
